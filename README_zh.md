# UECapUpdater

[English](README.md) | [繁體中文]

一個專為 Google Pixel 系列（搭載 Tensor / 三星基帶架構）設計的高性能基帶配置動態注入工具。透過穿透系統命名空間隔離，將自定義的 `.binarypb` 配置直接綁定掛載至基帶守護進程中，實現即時、無磚風險的網絡能力升級。

## 💡 這個 App 可以做什麼

* **即時閃刷自定義電信商配置**：直接將您的 `*.binarypb` 檔案虛擬注入到執行中的基帶檔案系統中，完全無需修改 `/vendor` 分區的唯讀區塊。
* **極速單檔批次掛載**：重構底層掛載機制，將過去多次穿透 `nsenter` 命名空間的 IO 阻塞作法，優化為「一次性批次處理」，大幅飆升套用速度。
* **直接提取並匯總 Magisk 模組**：允許直接從儲存空間選取多個含有基帶配置的 Magisk `.zip` 刷機包，全自動背景解壓、歸納並批量套用。
* **真·實時交錯日誌流滾動**：將 App 內部的指令執行步驟與底層 `shamp`/`UECAP` 的日誌輸出完美重組，配合控制台自動滾動置底，帶來即時掌控的流式反饋。
* **雙層硬體狀態精準鎖定**：拒絕日誌關鍵字的盲目猜測等待，直接結合 Android 通訊註冊表與 `shamp` 進程初始化特徵，確保在訊號完全同步後才放行。
* **全自動生成開機掛載模組**：每次閃刷成功後，自動在背景生成持久化的系統化啟動掛載腳本，保障手機重啟後修改依然完美生效。
* **一鍵秒回歸官方原廠狀態**：瞬間清空 PID 1 空間內的所有動態虛擬掛載，強迫基帶守護進程在幾秒內安全降級，乾淨地回歸官方唯讀韌體。

## 📖 使用說明

### 1. 準備工作
* 確保您的 Pixel 設備已在 Magisk 中允許此 App 獲取完整的 Root 權限。
* 將您自定義的電信商基帶配置文件（如 `lte_xxx.binarypb`）準備妥當並存放在手機儲存空間中。

### 2. 單檔套用模式
1. 在 App 內切換至 **單檔套用** 標籤頁。
2. 點擊 **選擇檔案**，選取一或多個配置檔，介面將即時顯示 `✅ X 個檔案已準備好`。
3. 點擊 **套用並重啟**。實時控制台會開始流式滾動印出：穿透 PID 1、批量綁定掛載、以及強殺強啟基帶的完整歷程。
4. 靜待控制台跳出 `[INFO] Signal lock confirmed! Awaiting UECAP file reads...` 並結束 5 秒的倒數緩衝，右上角訊號亮起即代表套用成功。

### 3. 模組提取模式
1. 切換至 **模組提取** 標籤頁。
2. 點擊 **選擇模組**，直接載入含有基帶配置的 Magisk 刷機 `.zip` 壓縮包。
3. App 將全自動在背景解壓、解析目錄樹、動態匯總所有有效二進位配置並執行批量注入。

### 4. 恢復原廠基帶
* 隨時在單檔頁面點擊 **恢復原廠基帶**，App 將瞬間清空 PID 1 的動態掛載，迫使基帶進程（`shamp`）在幾秒內安全降級、回歸唯讀官方韌體。

## 🚀 技術原理簡述

本工具透過以下階段實現系統級無損修改：
1. **空間穿透**：利用 `nsenter -t 1 -m` 穿透進入 PID 1 的頂層隔離空間。
2. **全局綁定**：將本地暫存區檔案以 `bind` 模式掛載至 `/vendor/firmware/uecapconfig/`。
3. **射頻冷啟動**：強殺基帶核心進程（`rild`, `shamp` 等）觸發硬體重啟，迫使基帶解析器重新載入已被動態替換的全新頻段組合。
